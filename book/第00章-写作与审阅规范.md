# 第 00 章 · 写给读者：这本书的写法与用法（写作与审阅规范）

> 这一章不讲解时间序列本身，而是说明**这本书如何被写出来、如何被审阅、你该如何读它**。对读者而言它是一份"使用说明书"；对写作过程而言它是约束每一章的**规范与审阅清单**。

---

## 0.1 这本书写给谁

- **目标读者**：完全没有统计学与编程基础的**零基础学习者**，以及想系统梳理知识框架的中级学习者。
- **写作第一原则**：*"每一步都必须能被一个零基础的人完全理解——知道'做了什么'、'为什么这么做'、'会得到什么效果'。"* 任何一步做不到这一点，就是本章需要返工的信号。

## 0.2 全书地图

```
第一部分 基础概念（第 1–2 章）   —— 时间序列长什么样、由什么构成
第二部分 统计语言准备（第 3–5 章）—— 描述"不确定"的数学语言
第三部分 经典统计方法（第 6–12 章）—— 从平滑到 ARIMA、状态空间、GARCH、协整
第四部分 机器学习与深度学习（第 13–16 章）—— 从特征工程到 Transformer、扩散
第五部分 前沿研究（第 17–19 章）  —— 基础模型、LLM、评估与因果
第六部分 实践与收尾（第 20–21 章 + 附录）—— 端到端案例、全书回顾、工具与术语表
```

每一章都遵循统一模板（见 0.3），并且**每一章写完都必须经过审阅循环**（见 0.4）才能进入下一章。

## 0.3 每一章的统一模板

每章固定包含以下部分，顺序不变：

1. **本章目标**：一句话说明学完后你能做什么。
2. **动机**：为什么需要这个方法/概念？不解决它会遇到什么问题？（用真实场景开篇）
3. **是什么**：概念讲解，零基础可懂；数学公式的每个符号都逐一解释；配直觉类比。
4. **怎么做**：分步骤展开。**每一步都包含三要素**：
   - *做什么*（操作本身）
   - *为什么这么做*（动机与理由）
   - *会怎样*（这一步产生的效果，好与坏的副作用都要说）
5. **完整示例**：一个数字算例（尽量小、可手算），从输入到输出走一遍。
6. **这个环节可能遇到的问题**：该环节（收集数据/预处理/建模/估计/诊断/预测）的**常见陷阱清单**——失败模式、误解、伪回归等。
7. **相似问题与已有解决方案**：本环节的困难，历史上/其他领域是否遇到过相似问题？如何被解决？（跨章节呼应，避免重复造轮子）
8. **本章小结**：3–6 句话概括。
9. **练习与自测**：3–5 题，标注难度 ★（可心算）★★（需动手）★★★（需编程/查资料），附简答提示。
10. **本章审阅记录**：审阅日期、发现的问题、修订内容（见 0.4）。

## 0.4 审阅循环（每章必做，写完即审）

写完一章后，按以下清单逐项检查并修订，然后把结果写进该章"审阅记录"：

| # | 审阅项 | 检查方法 | 通过标准 |
|---|---|---|---|
| R1 | 零基础可理解性 | 逐句检查：是否有未定义的术语/符号？是否有跳跃？ | 任何首次出现的术语在出现处或之前有解释；每个公式符号有定义 |
| R2 | "为何行动"完整 | 检查每个"怎么做"步骤 | 每一步都能回答"为什么这么做"，若不能，补一句动机 |
| R3 | "效果"明确 | 检查每个操作描述 | 每一步都说明"会得到什么/副作用是什么" |
| R4 | 陷阱覆盖 | 对照本章主题 | 至少列出 3 个该环节的真实失败模式（有文献或公认教训依据） |
| R5 | 相似问题映射 | 检查第 7 部分 | 本章困难有明确的历史/跨领域对应与解决方式 |
| R6 | 示例可复现 | 手算/心算示例 | 示例数字自洽，读者可自行验证 |
| R7 | 章节衔接 | 开头与结尾 | 开头承接前章，结尾预告下章（"下一章我们将……"） |
| R8 | 练习有效 | 每道题对照本章内容 | 每道题至少考察一个本章知识点 |

**审阅方式**：作者自查（R1–R8 逐项）为主；对重点章节（第 1、4、8、15、17 章）额外请一名"模拟零基础读者"（独立审阅者）通读并反馈不懂之处，反馈逐条处理或解释。

**修订规则**：审阅发现的问题按 严重（读者必然卡住）/ 中等（易误解）/ 轻微（措辞）分级；严重问题必须修订后才能进入下一章；中等与轻微问题在当章或下一章开头修订。

## 0.5 术语与符号规范

- 中文术语首次出现时附英文原文，如 **平稳性（stationarity）**；后续只用中文。
- 数学符号：希腊字母与下标在出现处用文字解释（如 "γ(k)：间隔 k 的自协方差"）。
- 公式一律 Markdown 文本形式，不依赖渲染器；复杂公式配文字版解释。
- 所有历史文献引用：作者（年份），首次出现附全名与出处；前沿论文附 arXiv 编号。
- 每章不超过约 7000 字，宁可拆章不可压缩解释。

本规范在全书完成时再审阅一次：检查各章是否真的遵守了模板与清单（R9：全书一致性）。
