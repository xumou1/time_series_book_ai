# 第 9 章 · 状态空间与卡尔曼滤波：在噪声中追踪隐藏状态

**本章目标**：学完本章后，你能①说出状态空间模型的两类方程（状态方程、观测方程）各自管什么；②理解卡尔曼滤波"预测-更新"两拍的直觉；③列举状态空间模型相对 ARIMA 的三个优势（缺失值、多源数据、时变参数）；④明白"滤波/平滑/预测"三个词的差别。

---

## 9.1 动机：有些东西看不见，却一直在动

想象追踪一枚导弹：你只能通过雷达**测到它的位置，而且测量有噪声**。但真正重要的是"它的真实位置和速度"——那是看不见的。ARIMA 只对"看得见的观测"建模；但很多问题的本质是**"看不见的状态"在演化，观测只是状态的加噪投影**：

- 导弹：状态 = 位置+速度；观测 = 雷达读数；
- 气温预测系统：状态 = 真实气温的演化；观测 = 传感器读数（有误差）；
- 宏观经济：状态 = 潜在 GDP；观测 = 官方统计（有修正、有噪声）；
- 股票：状态 = 真实波动率；观测 = 日收益率。

> 一句话：**状态空间模型假设"世界由隐藏状态驱动"，卡尔曼滤波是从噪声观测中实时"追"这些状态的方法。** 它是阿波罗登月导航的核心算法，也是今天自动驾驶、金融滤波、气象同化的标准工具。

---

## 9.2 是什么：两个方程 + 一个滤波器

### 9.2.1 状态空间模型的两个方程

**状态方程（怎么演化）**：

```
s_t = F·s_{t−1} + w_t
```

**观测方程（怎么看到）**：

```
x_t = H·s_t + v_t
```

| 记号 | 含义 |
|---|---|
| `s_t` | **隐藏状态**（如位置+速度），看不见 |
| `x_t` | **观测值**（雷达读数），看得见 |
| `F` | 状态转移矩阵：状态怎么从上一刻演化过来 |
| `H` | 观测矩阵：状态如何"投影"成观测 |
| `w_t` | 过程噪声（状态演化本身的不确定） |
| `v_t` | 观测噪声（测量误差） |

**讲人话**：*状态按规律演化（F），但演化有噪声（w）；我们能看到的只是状态的加噪投影（H、v）。问题：从观测反推状态。*

> 对比 ARIMA：ARIMA 只建模"观测自己"；状态空间建模"状态→观测"两层结构。**ARIMA 是"平房"，状态空间是"两层楼"**——二楼是隐藏状态，一楼是观测。

### 9.2.2 卡尔曼滤波：两拍循环

Kalman (1960) 给出的递推算法，每来一个新观测，做两拍：

```
预测拍： 用上一刻的状态预测这一刻的状态（和它的不确定度）
更新拍： 拿新观测校正预测——观测与预测差多少，就修正多少
```

- **预测拍**（做什么/为什么）：状态按 F 演化一步，不确定度变大（演化有噪声）。
- **更新拍**（做什么/为什么）：把"预测"和"新观测"按各自的不确定度**加权平均**——观测越可靠，越相信观测；预测越可靠，越相信预测。这个权重叫**卡尔曼增益**（Kalman gain）。
- **效果**：输出"当前状态的最佳估计 + 它的不确定度"，然后循环进入下一时刻。

**直觉类比（导航）**：你边开车边看导航。车速表告诉你"我大概在哪儿"（预测），GPS 告诉你"应该在这儿"（观测）——两者都有误差。卡尔曼滤波就是自动算"该信谁多一点"的智慧：GPS 漂移大时多信车速积分，车速积分发散时多信 GPS。

### 9.2.3 三个近义词，别混

| 词 | 用哪些数据 | 目的 |
|---|---|---|
| **滤波（filtering）** | 只用**过去到当前**的观测 | 实时估计当前状态（导航、在线监控） |
| **平滑（smoothing）** | 用**全部**观测（含未来） | 事后重估历史状态（考古式，画历史轨迹） |
| **预测（prediction）** | 只用过去的观测 | 估计**未来**状态（预测） |

## 9.3 怎么做：五个关键决策

### 第 1 步 · 定状态（最重要的一步）
- **做什么**：决定"隐藏状态 s_t 是什么"。常见选择：观测本身+趋势（局部水平模型）、水平+斜率（线性增长模型）、真实波动率等。
- **为什么**：状态定义决定模型的解释力——这是建模者的"设计"而非自动的。
- **会怎样**：状态选得好，滤波输出可直接解释（"潜在趋势"）；选得差，一切白搭。

### 第 2 步 · 写方程（定 F、H）
- **做什么**：写出状态方程与观测方程（线性用矩阵 F、H；非线性用扩展卡尔曼 EKF，软件处理）。
- **为什么**：F 是"规律"，H 是"观测方式"，它们是模型的骨架。
- **会怎样**：模型被完全指定，剩下的是估计噪声参数。

### 第 3 步 · 估计噪声参数
- **做什么**：用数据估计 w、v 的方差（极大似然或软件自动）。
- **为什么**：噪声大小决定"信预测还是信观测"（卡尔曼增益的原料）。
- **会怎样**：得到调好的滤波器——**噪声参数错误会让滤波结果要么太飘要么太钝**。

### 第 4 步 · 跑卡尔曼滤波（预测-更新循环）
- **做什么**：从 t=1 到 T 逐时刻执行"预测拍→更新拍"，得到每个时刻的状态估计及其不确定度。
- **为什么**：这是实时追踪——每来一个新观测立即更新，天然单边（只用过去），无泄漏。
- **会怎样**：得到平滑的"去噪状态轨迹"（比如干净的导弹轨迹），且每个点带误差棒。

### 第 5 步 · 预测与诊断
- **做什么**：预测 = 让状态方程继续往前走；诊断 = 看"新息"（观测−预测的差）是否白噪声。
- **为什么**：新息是滤波的"残差"，它不白说明模型错了（F、H 或噪声参数）。
- **会怎样**：新息白 → 滤波器健康；不白 → 回去改模型。

## 9.4 完整示例：一维"水平+噪声"跟踪（手算可复现）

最简单的状态空间：**状态 = 真实水平 μ（恒定），观测 = μ + 噪声 v**（比如测量一个稳定电压）。

```
状态方程：s_t = s_{t−1}（F=1，无过程噪声）
观测方程：x_t = s_t + v_t（H=1，观测噪声方差 σ²_v = 4）
```

初始：ŝ₁ = 0，不确定度大。观测序列：`x₁=2, x₂=3, x₃=1`（真值 μ 未知，假设真值=2.5，噪声 ±1.5 左右）。

**卡尔曼递推（直觉版，权重 = 各自不确定度的反比）**：
- t=1：只有观测 x₁=2 → 估计 ŝ₁ = 2（没有其他信息，直接信观测）。
- t=2：观测 3 到来 → 与上一估计 2 折中。若两者不确定度相当，取平均 → ŝ₂ ≈ 2.5。
- t=3：观测 1 → 继续折中 → ŝ₃ ≈ 2.0。
- 最终：估计收敛在 2~2.5 附近——**平均下来接近真值 2.5，且单点噪声（1）没有把估计拉得太远**。

**效果**：卡尔曼滤波做的本质是**带权重的递推平均**——但权重是**自动按不确定度算出来的**，且每一刻只用到当前及过去的信息（单边、可实时）。这就是"在噪声中追踪隐藏状态"的含义。

## 9.5 这个环节可能遇到的问题（陷阱清单）

1. **状态定义拍脑袋**：状态不是自动的，是设计出来的——**状态定义决定了模型能说什么**；定义错误（如把随机游走当恒定水平）会导致滤波发散或过度平滑。
2. **噪声参数瞎设**：观测噪声设太小 → 完全相信观测、滤波等于没滤；设太大 → 完全不信观测、滞后严重。**必须用数据估计或调参。**
3. **把"滤波"当"预测"**：滤波估计的是**当前**状态；预测是**未来**状态。报告时混用会让决策者误读。
4. **非线性硬套线性**：真实系统非线性（如卫星轨道）用线性卡尔曼会发散——**需要扩展卡尔曼（EKF）或无迹卡尔曼（UKF）**。
5. **忽视"新息诊断"**：滤波结果"看起来不错"不代表模型对——**新息不白 = 模型结构错**，要回头改。
6. **与 ARIMA 的适用性混淆**：ARIMA 对纯观测序列（无结构分层）更简单直接；**状态空间在"有隐藏状态、缺失值、多源观测"时优势明显**——选错场景等于自找麻烦。

## 9.6 相似问题与已有解决方案：历史回响

| 本环节的困难 | 谁遇到过 | 如何解决 | 本书对应 |
|---|---|---|---|
| "从噪声观测追状态" | Kalman (1960)、Kalman & Bucy (1961) | **卡尔曼滤波**：预测-更新两拍；阿波罗登月验证 | 本章 |
| "非线性系统" | 航天控制（1960s-70s） | **扩展卡尔曼（EKF）**、无迹卡尔曼（UKF） | 本章 |
| "时序里的状态空间怎么用" | Akaike (1974)、Harvey (1989) | **结构性时间序列模型**：趋势、季节、回归项都写成状态 | 本章 |
| "缺失值怎么办" | 状态空间理论 | 缺失时刻跳过更新拍即可——**天然处理缺失**（ARIMA 做不到） | 本章；第 2 章缺失问题 |
| "深度学习版本" | 2010s | **Deep State Space**（概率状态空间+神经网络），第 16 章提；神经 ODE（连续时间状态） | 第 16 章 |

**核心启示**：状态空间是"结构建模"的巅峰范式——**把领域知识（隐藏状态、过程规律、观测误差）显式写进模型**，换来缺失值、多源融合、在线追踪三大能力。深度学习时代它并未过时，反而被吸收（Deep State Space、神经 ODE）。

## 9.7 本章小结

1. **状态空间** = 状态方程（隐藏状态演化）+ 观测方程（加噪投影）；ARIMA 是"平房"，它是"两层楼"。
2. **卡尔曼滤波**：预测拍（状态外推）→ 更新拍（按不确定度加权折中），循环递推，**单边、实时、无泄漏**。
3. 三大优势：**缺失值天然处理、多源观测融合、时变参数**（结构性时间序列）。
4. 区分：滤波（现在）、平滑（事后全数据）、预测（未来）。
5. 诊断靠**新息**（观测−预测），不白就回头。

下一章回到金融战场：**波动率**——均值模型全都假设方差恒定，而金融数据的方差本身在变。第 10 章 · 波动率建模：ARCH 与 GARCH。

**简答提示**：1 状态方程管"隐藏状态怎么演化"，观测方程管"状态如何投影成观测"；2 预测拍=按规律外推状态并增大不确定度，更新拍=用新观测按不确定度加权校正；3 缺失时刻没有新观测，跳过"更新拍"、只用"预测拍"即可——不需要任何特殊处理；4 滤波估计当前状态（只用过去到现在的数据），预测估计未来状态；5 两种模型应给出相近预测，状态空间多一个"可解释的潜在状态轨迹"。
