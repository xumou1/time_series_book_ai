# 第 11 章 · 多变量时间序列：VAR、协整与误差修正

**本章目标**：学完本章后，你能①用一句话解释 VAR；②解释"协整"如何把第 4 章的伪回归从陷阱变成工具；③理解误差修正模型的"长期均衡+短期修正"直觉；④说出格兰杰因果检验检验的是什么（以及不是什么）。

---

## 11.1 动机：变量之间会"互相说话"

前几章都是**单变量**：只有一个序列，用自己的历史预测自己。但现实几乎总是多变量的：利率影响汇率，汇率影响出口，出口影响 GDP……**变量互相影响，信息藏在交叉项里**。

多变量建模有三个经典难题，本章逐一解决：

1. **互相影响怎么建模？** → VAR（让每个变量都听别人的过去）
2. **多个非平稳序列：伪回归还是真关系？** → 协整（第 4 章的陷阱在这里反转成工具）
3. **短期波动与长期均衡怎么统一？** → 误差修正模型（ECM）

> 一句话：**单变量建模回答"这一个序列怎么动"；多变量建模回答"这几个序列为什么一起动、谁带动谁、动完会不会回到均衡"。**

---

## 11.2 是什么：三件工具

### 11.2.1 VAR(p)：向量自回归

**VAR（Vector Autoregression，向量自回归）**：把单变量 AR 推广到多变量——**每个变量都用所有变量（包括自己）的滞后值来回归**。

以两个变量（x、y）的 VAR(1) 为例，两个方程：

```
x_t = c₁ + a₁₁·x_{t−1} + a₁₂·y_{t−1} + ε₁t
y_t = c₂ + a₂₁·x_{t−1} + a₂₂·y_{t−1} + ε₂t
```

- `a₁₂`：y 的过去对 x 现在的影响（**交叉影响**）；
- `a₂₁`：x 的过去对 y 现在的影响；
- 残差 ε₁t、ε₂t 允许互相相关（同期联动）。

**直觉**：*x 和 y 互相看对方的"脸色"——但都只看过去（没有未来泄漏）。*

**为什么用 VAR**：当你**不知道因果方向**时（利率影响汇率还是汇率影响利率？），VAR 让数据自己说话——不预设方向，把所有滞后都放进去。配套工具：
- **脉冲响应函数（IRF）**：给 x 一个冲击，看 y 随后几期怎么反应——"一个冲击如何传染"；
- **方差分解**：y 的波动有多少来自 x 的冲击——"谁主导谁"。

### 11.2.2 协整（cointegration）：伪回归的解药

回到第 4 章的伪回归：两个 I(1) 序列（非平稳，有单位根）做回归会得到虚假的高相关。但 Engle & Granger (1987) 发现了重要的例外：

> **如果两个非平稳序列的某个线性组合是平稳的**（比如"消费 − 0.9×收入"围绕 0 波动），那么它们之间存在**长期均衡关系**——这叫**协整**。

```
消费_t 和 收入_t 都非平稳（都随经济一起涨）
但  消费_t − 0.9·收入_t ≈ 平稳（围绕一个常数波动）
→ 消费与收入协整：0.9 是长期弹性，偏离会被拉回
```

**为什么这不是伪回归**：伪回归的两个序列**各自漂移、互不相干**，组合后还是非平稳；协整序列**互相约束**——短期可以偏离，但长期会被"拉回"均衡线。**相关来自真实的机制（共同均衡），不是共同的时间位置。**

> 关键区分（背下来）：**协整 = 有长期均衡的"真关系"；无协整 = 各自漂移的"假关系"。** 伪回归的陷阱只对"无协整"成立。

### 11.2.3 误差修正模型（ECM）：把短期和长期焊在一起

**ECM** 把"短期动态"和"长期均衡"放进同一个模型：

```
Δx_t = （短期项：Δx_{t−1}, Δy_{t−1} 等） + γ·(x_{t−1} − β·y_{t−1}) + 噪声
```

- 括号 `x_{t−1} − β·y_{t−1}`：**上期偏离均衡的程度**（误差）；
- `γ`（通常为负）：**修正速度**——偏离均衡多远，本期就拉回多少。

**直觉（橡皮筋）**：消费和收入之间有一根橡皮筋（长期均衡）。短期任何冲击都可以让消费偏离（橡皮筋被拉长），但下期橡皮筋会把消费**拉回均衡线**——γ 就是橡皮筋的"劲"。

**为什么需要它**：只差分（第 8 章）会丢掉长期均衡信息（两个协整序列差分后不再有均衡约束）；只做水平回归会伪回归。**ECM 两全：短期动态 + 长期均衡。**

### 11.2.4 格兰杰因果（Granger causality）：一个"预测"意义上的因果

**格兰杰因果检验**：*如果 x 的过去能显著改进对 y 的预测，就说"x 格兰杰因果于 y"*（在控制了 y 自身历史之后）。

- **注意**：这是**统计预测意义**的因果，不是哲学/物理意义（"鸡叫格兰杰因果于日出"——鸡叫确实帮助预测日出，但鸡叫不导致日出）。
- **用途**：初筛"谁领先谁"；**千万别在报告里写成"x 导致 y"**（第 4、19 章的忠告再强调一次）。

## 11.3 怎么做：五步流程

### 第 1 步 · 逐序列平稳性检验
- **做什么**：对每个序列跑第 4 章流程（ADF/KPSS），记录"单整阶数"（差几次才平稳，I(0)/I(1)）。
- **为什么**：协整要求各序列**同阶单整**（通常都 I(1)）；阶数不同则协整无意义。
- **会怎样**：得到"全部 I(1)"或"混合"的结论，决定走哪条路。

### 第 2 步 · 协整检验
- **做什么**：全部 I(1) → 检验是否存在协整（Engle-Granger 两步法：先回归取残差，再对残差做单位根检验；或 Johansen 检验处理多个协整向量）。
- **为什么**：决定"能不能谈长期关系"——有协整走 ECM，无协整只能差分后建 VAR。
- **会怎样**：两个分支：**有协整**（真关系，建 ECM）或**无协整**（假关系，差分建 VAR）。

### 第 3 步 · 建模
- **做什么**：有协整 → ECM（估计长期 β 与修正速度 γ）；无协整 → 差分后 VAR（选阶用 AIC）。
- **为什么**：ECM 保长期信息，VAR 只做短期——按第 2 步的证据选。
- **会怎样**：得到一组方程，系数都有解释（β=长期弹性、γ=修正速度）。

### 第 4 步 · 诊断
- **做什么**：检查残差（各自白噪声、无遗漏滞后）；必要时加大阶数。
- **为什么**：残差有结构 = 模型没抓全变量间关系。
- **会怎样**：模型合格，进入解读。

### 第 5 步 · 解读与预测
- **做什么**：①看 γ 的大小（修正快慢）；②跑脉冲响应（给 x 一个冲击，看 y 的反应路径）；③格兰杰因果检验（谁领先谁）；④预测。
- **为什么**：多变量模型的产出不只是预测，更是**机制解读**——"冲击怎么传导"。
- **会怎样**：得到"冲击传导图"与预测，向决策者解释"哪个变量驱动哪个"。

## 11.4 完整示例：消费与收入的协整（概念手算）

假设长期均衡 `消费 = 0.9×收入`，修正速度 γ = −0.3，ECM 简化成：

```
Δ消费_t = 短期项 + (−0.3)·(消费_{t−1} − 0.9×收入_{t−1})
```

**情景**：某期消费比均衡值高 1（比如 消费−0.9×收入 = +1——消费过度）。

```
修正项 = −0.3 × (+1) = −0.3
→ 下一期消费被拉回 0.3（约 30% 的偏离被修正）
```

**观察**：偏离 1 → 一期修掉 0.3，偏离剩 0.7；下一期再修 0.3×0.7=0.21……**偏离按 γ 的比例逐步衰减回均衡**——这就是"误差修正"的字面含义。γ=−0.3 表示"每期修正 30%"。

**效果**：你看到了橡皮筋怎么工作——**短期随便跑，长期被均衡拉着走**。这也解释了协整序列为何"一起动"：它们被同一根橡皮筋拴着。

## 11.5 这个环节可能遇到的问题（陷阱清单）

1. **不检验单整直接回归**：第 4 章伪回归的现场版。**先 ADF，再谈关系。**
2. **把格兰杰因果当真因果**：鸡叫问题。**报告里写"领先关系/预测改进"，不写"导致"。**
3. **协整解释过度**：β 估计显著≠经济含义正确（可能只是统计均衡）。**解释 β 要有经济理论支撑。**
4. **忽略协整直接差分**：把长期均衡信息差没了——**有协整就该 ECM。**
5. **小样本硬上 VAR**：VAR 参数随变量数平方增长（2 变量 VAR(2) 已 10+ 参数）——**变量和阶数都要克制，样本不足会过拟合。**
6. **脉冲响应不给置信区间**：IRF 是估计出来的，有不确定性——**软件默认给置信带，别关。**
7. **同阶单整条件忽略**：I(1) 和 I(2) 混在一起谈协整——**先核对单整阶数。**

## 11.6 相似问题与已有解决方案：历史回响

| 本环节的困难 | 谁遇到过 | 如何解决 | 本书对应 |
|---|---|---|---|
| "多变量互相影响" | Sims (1980) 宏观计量革命 | **VAR** 与脉冲响应（诺贝尔经济学奖 2011） | 本章 |
| "伪回归 vs 真关系" | Engle & Granger (1987) | **协整**：线性组合平稳 = 长期均衡（诺贝尔经济学奖 2003） | 本章；第 4 章 |
| "多个协整向量" | Johansen (1988, 1991) | **Johansen 检验**与 VECM | 本章 |

**核心启示**：多变量时序的真正难度不是公式，而是**判断"关系是真是假"**——协整检验是伪回归的裁判；而"因果"二字必须永远加引号（预测意义）。这为第 19 章的因果推断埋下伏笔。

## 11.7 本章小结

1. **VAR**：所有变量互相回归——不知道因果方向时让数据说话；配脉冲响应看"冲击怎么传导"。
2. **协整**：非平稳序列的线性组合平稳 = 长期均衡；**有协整是真关系，无协整是伪回归**（第 4 章陷阱的解药）。
3. **ECM**：短期动态 + γ×(上期偏离均衡) 修正项——"橡皮筋"把短期拉回长期。
4. **格兰杰因果**：预测意义上的"领先关系"，**不是因果**。
5. 流程：**单整检验 → 协整检验 → 分支建模（ECM 或差分 VAR）→ 诊断 → IRF/预测**。

下一章处理"规则突然改变"：**马尔可夫机制转换**——同一个序列，可能在"扩张/衰退"两个状态间跳来跳去。第 12 章 · 非线性与机制转换：马尔可夫转换模型。

## 11.8 练习与自测

1. ★ VAR 和单变量 AR 的本质区别是什么？（提示：11.2.1）
2. ★ 协整的定义是什么？它如何避开伪回归？（提示：11.2.2）
3. ★★ ECM 里 γ=−0.4，某期偏离均衡 +2，下一期预计修正多少？（提示：11.4）
4. ★★ 为什么"鸡叫格兰杰因果于日出"说明格兰杰因果≠因果？（提示：11.2.4）
5. ★★★ 用 `statsmodels` 的协整检验对"消费 vs 收入"类真实数据（或自造协整序列）跑一次 Engle-Granger，报告检验结论并解释"长期均衡"。（提示：11.3 五步）

**简答提示**：1 AR 只用自己历史，VAR 用所有变量的历史（含交叉影响）；2 非平稳序列的线性组合平稳＝协整；组合平稳意味着偏离被拉回（机制约束），而非各自漂移（假相关）；3 修正 = −0.4×2 = −0.8（偏离被拉回 0.8）；4 鸡叫确实改善对日出的预测，但鸡叫不导致日出——格兰杰因果只检验"预测改进"；5 略。
