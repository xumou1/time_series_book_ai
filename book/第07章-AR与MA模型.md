# 第 7 章 · 从回归到 AR/MA：让过去自己说话

**本章目标**：学完本章后，你能①用一句话解释 AR(p)、MA(q)、ARMA(p,q) 分别假设了什么；②背出 ACF/PACF 识别表并应用；③手算一个 AR(1) 的预测；④说出平稳性对 AR 系数的约束意味着什么。

---

## 7.1 动机：从"加权"到"解释"

第 6 章的指数平滑是**加权过去**：好用，但它不解释"数据为什么这样动"——它只是一台平滑机器。本章的 AR/MA 换一个思路：**假设数据的生成机制**，然后从数据里把机制"挖"出来。

两种基本假设，对应两类模型：

- **AR（自回归）**：今天的值**由过去的观测值决定**——"昨天值高，今天倾向也高"。
- **MA（滑动平均）**：今天的值**由过去的随机冲击决定**——"昨天的意外冲击，今天还有余波"。

> 一句话：**AR 用"看得见的过去"（观测值）解释现在，MA 用"看不见的过去"（冲击）解释现在。** 真实序列往往两者都有 → ARMA。

为什么值得学：它是 Box–Jenkins 方法（第 8 章 ARIMA）的地基，也是"模型识别 → 估计 → 诊断"这套**工作流**的首次完整登场——这套工作流今天仍是所有建模的标准流程。

---

## 7.2 是什么：三个模型

### 7.2.1 AR(p)：自回归

**AR(p) 模型**（p 阶自回归）：

```
x_t = c + φ₁·x_{t−1} + φ₂·x_{t−2} + … + φ_p·x_{t−p} + ε_t
```

- `c`：常数（截距）；
- `φ₁…φ_p`（读作 phi）：**自回归系数**——每个过去观测的"影响力"；
- `ε_t`：白噪声冲击（第 3 章）。

**AR(1) 特例**（只有一个过去值）：

```
x_t = c + φ·x_{t−1} + ε_t
```

- φ>0：今天高 → 明天倾向也高（**惯性**，如气温）；
- φ<0：今天高 → 明天倾向回落（**回摆**，如价格修正）；
- φ=0：没有记忆（白噪声加常数）。

**平稳条件（必记）**：AR(1) 平稳要求 **|φ| < 1**。为什么？冲击的传导是 φ、φ²、φ³……**|φ|<1 时冲击随时间消退**，序列围绕长期均值波动；|φ|≥1 时冲击永不消退，序列"漂走"（这就是第 4 章"单位根"的 AR 面孔——φ=1 是随机游走）。

**长期均值**：AR(1) 会被拉向 `c/(1−φ)`——**均值回归**（mean reversion）。

### 7.2.2 MA(q)：滑动平均

**MA(q) 模型**（q 阶滑动平均）：

```
x_t = μ + ε_t + θ₁·ε_{t−1} + θ₂·ε_{t−2} + … + θ_q·ε_{t−q}
```

- `μ`：长期均值；
- `θ₁…θ_q`（读作 theta）：**冲击系数**——过去冲击的"余波强度"；
- `ε_t`：白噪声冲击。

**MA(1) 特例**：`x_t = μ + ε_t + θ·ε_{t−1}`。直觉：**今天的值 = 长期水平 + 今天的冲击 + 昨天冲击的一点余波**。比如"某天促销的冲击，第二天还有小幅余波"。

**为什么需要 MA**：有些序列的依赖"记不住具体数值，只记得冲击"。用 AR 表达这种依赖可能需要几十项，用 MA 一两项就够——**简约**。理论保证：**Wold 分解定理**说任何"纯非确定"平稳过程都可以写成 MA(∞)，所以"用冲击表示"有普遍基础。

### 7.2.3 ARMA(p,q)：合体

**ARMA(p,q)** = AR(p) + MA(q)：

```
x_t = c + φ₁x_{t−1} + … + φ_p x_{t−p} + ε_t + θ₁ε_{t−1} + … + θ_q ε_{t−q}
```

**直觉**：*既用观测值的惯性，又用冲击的余波*。比如温度：昨天的温度有惯性（AR），一场寒潮的冲击还有两天余波（MA）。

### 7.2.4 识别表：ACF/PACF 怎么告诉我们 p、q（背下来）

第 5 章学过：ACF 看总相关，PACF 看剔除中间滞后后的直接相关。结果是：

| 模型 | ACF | PACF |
|---|---|---|
| **AR(p)** | 拖尾（缓慢衰减，如指数式） | **p 阶后截尾**（突然归零） |
| **MA(q)** | **q 阶后截尾** | 拖尾 |
| **ARMA(p,q)** | 拖尾 | 拖尾 |

**为什么**：AR(1) 的记忆是"传导链"（x_t→x_{t−1}→x_{t−2}…），所以总相关 ρ(k)=φ^k 一直衰减（拖尾）；但剔除中间环节后，x_t 与 x_{t−2} 的**直接**关系是 0（PACF 截尾）——**记忆靠链条，链条一断就没了**。MA(1) 恰好反过来：直接记忆只有 1 步（ACF 截尾），但"间接"关系永远存在（PACF 拖尾）。想不通就先背表，第 7.4 节有数字例子。

## 7.3 怎么做：完整工作流（Box–Jenkins 的前半）

### 第 1 步 · 平稳化
- **做什么**：按第 4 章五步判断平稳；不平稳先差分/去趋势（第 8 章细说）。
- **为什么**：ARMA 的一切理论（估计、检验、预测区间）都以平稳为前提；非平稳拟合会得到 φ≈1 的"假模型"。
- **会怎样**：得到平稳序列，进入识别。

### 第 2 步 · 识别（定 p、q）
- **做什么**：画 ACF/PACF，对照识别表定阶。
- **为什么**：ACF/PACF 的截尾/拖尾是数据给的"指纹"，避免瞎猜阶数。
- **会怎样**：得到候选模型，如 AR(1) 或 MA(1) 或 ARMA(1,1)。

### 第 3 步 · 估计（φ、θ 的值）
- **做什么**：用软件（极大似然估计）拟合，得到系数估计值与标准误。
- **为什么**：选择"最可能产生这串数据"的系数——极大似然的直觉是"让模型说'这数据很像我'"。
- **会怎样**：得到带系数的模型，如 x_t = 2 + 0.6x_{t−1} + ε_t。

### 第 4 步 · 诊断
- **做什么**：检验残差是否白噪声（Ljung–Box 检验；ACF 图看残差）。
- **为什么**：残差还有相关 = 模型没挖干净，阶数可能不够。
- **会怎样**：残差白 → 模型合格；不白 → 回到第 2 步加大阶数，或考虑季节（第 8 章）。

### 第 5 步 · 预测
- **做什么**：多步预测（软件输出点预测+区间）。AR(1) 的 h 步预测：`x̂_{T+h} = c + φ·x̂_{T+h−1}`（逐步代回）。
- **为什么**：预测本质是"让模型继续演"。
- **会怎样**：远期预测收敛到长期均值（c/(1−φ)）——**AR 的预测会"回归均值"，这是它和指数平滑（水平线）的直观差别**。

## 7.4 完整示例：AR(1) 手算

模型：`x_t = 2 + 0.6·x_{t−1} + ε_t`。已知 x₁ = 10，ε₂ = 0.5。

```
x₂ = 2 + 0.6×10 + 0.5 = 2 + 6 + 0.5 = 8.5
```

**观察**：x₁=10 高于长期均值 c/(1−φ) = 2/0.4 = **5**，所以 x₂ 被拉回 8.5——**均值回归的力量**。若 φ=0.9，x₂ = 2+9+0.5 = 11.5（惯性更强，回得慢）；若 φ=−0.6，x₂ = 2−6+0.5 = −3.5（今天高明天就回摆）。

**ACF 验证**：AR(1) 的 ρ(k) = φ^k（φ=0.6：0.6, 0.36, 0.216…**指数拖尾**）；PACF 在 k=1 后**截尾**（ρ(1)=0.6，之后≈0）。对照识别表：AR(1)。——这就是"指纹"的现场演示。

**效果**：你刚刚完成了一次完整的"识别→估计→预测"演练；第 8 章会把"不平稳怎么办（差分）"补上，变成完整的 ARIMA。

## 7.5 这个环节可能遇到的问题（陷阱清单）

1. **用非平稳数据拟合 AR**：φ 估计值逼近 1，看似"很显著"，其实是随机游走的假象。**先平稳化，再谈 AR。**
2. **阶数贪多**：p、q 越大拟合越好，但预测越差（过拟合）。**用 AIC/BIC 惩罚复杂（第 19 章），别只看拟合优度。**
3. **识别表搞反**：AR 看 PACF 截尾，MA 看 ACF 截尾——反了会选错模型。
4. **把 MA 的冲击当可观测**：ε_t 是"看不见的"，不能像 AR 那样直接读过去值；MA 的估计与预测都更依赖软件。
5. **跳过残差诊断**：不看残差就宣布"模型完成"——残差不白，模型就是错的。
6. **忽视"简约性"**：能用 ARMA(1,1) 别用 ARMA(5,5)；参数越多越容易过拟合。
7. **把 AR 当因果**：AR 的 φ 只描述"统计依赖"，不代表"x_{t−1} 导致 x_t"（因果要第 11、19 章的专门工具）。

## 7.6 相似问题与已有解决方案：历史回响

| 本环节的困难 | 谁遇到过 | 如何解决 | 本书对应 |
|---|---|---|---|
| "阶数怎么定" | Box & Jenkins (1970) | **识别表**（ACF/PACF 截尾拖尾）+ 三阶段工作流 | 本章；第 8 章 |
| "阶数太多/太少" | Akaike (1974) | **AIC/BIC**：似然 + 参数数惩罚 | 第 19 章 |
| "残差是否白" | Box & Pierce (1970)、Ljung & Box (1978) | **Ljung–Box 检验**：检验残差自相关是否显著 | 本章 |
| "AR 和 MA 为何等价" | Wold (1938) | **Wold 分解定理**：任何纯非确定平稳过程 = MA(∞) | 本章 7.2.2 |
| "有趋势/季节怎么进模型" | Box & Jenkins (1970) | **差分 + SARIMA**（第 8 章）把非平稳也纳入框架 | 第 8 章 |

**核心启示**：AR/MA 的价值不在公式，而在**工作流**——平稳化、识别、估计、诊断、预测，每一步都有明确工具和明确失败模式。这套流程从 1970 年用到今天，是"建模纪律"的源头。

## 7.7 本章小结

1. **AR**：今天 = 过去观测的线性组合（"看得见的记忆"）；平稳要求 |φ|<1，有均值回归。
2. **MA**：今天 = 长期均值 + 过去冲击的组合（"看不见的记忆"）；Wold 定理给普遍性。
3. **ARMA** = AR + MA，兼顾两类记忆。
4. **识别表**：AR 的 PACF 截尾、MA 的 ACF 截尾（背下来）。
5. 工作流：**平稳化 → 识别 → 估计 → 诊断 → 预测**；残差不白就回头。

下一章把 ARMA 升级为完整的 Box–Jenkins 体系：**非平稳怎么办（差分）→ ARIMA；季节怎么办 → SARIMA**。第 8 章 · ARIMA 与 Box-Jenkins：一套完整建模工作流（重点章）。
