## 📚 书籍（`book/`）——零基础友好的完整教材（21 章 + 3 附录）

- 每个概念对零基础学习者**可完全理解**（术语逐项解释、公式逐符号定义）；

- 每章都有**"这个环节可能遇到的问题"**（陷阱清单）与**"相似问题与已有解决方案"**（历史回响表）；

## 🧪 示例项目（`examples/`）——uv 管理的可运行环境

配套的可运行项目：`examples/` 用 **uv** 管理 Python 环境（matplotlib/pandas/numpy/statsmodels），生成与书中数字一致的示例数据（`examples/data/`）和 9 张插图（`book/figures/`，嵌入第 1/2/4/5/6/8/10/15 章）。

```bash
cd examples
uv sync                                  # 安装依赖
uv run python scripts/make_data.py       # 生成示例数据
uv run python scripts/make_figures.py    # 生成书中插图
```

详见 [`examples/README.md`](examples/README.md)。

## 阅读建议

- **零基础系统学习**：按书籍章节 01 → 02 → … → 21 顺序阅读，每章末尾有练习与自测。
- **快速总览**：先读第 21 章（地图/主线/忠告）与第 00 章（写法），再回头细读。
- **写论文/做项目**：重点第 15、17、18、19 章（前沿与评估方法论），配合研究笔记第 03、04 章核对文献。
