# 文献索引 · 去重与状态跟踪

> 本表是文献管理的中枢：**唯一键去重 + 规范命名 + 状态机**。放入新文献前先查本表，避免重复下载/重复放入；每条文献登记状态，追踪"从下载到沉淀"的全生命周期。

## 规则（请先读）

1. **唯一键**：优先 arXiv ID（如 `2403.07815`）；无 arXiv 用 DOI 的主要段（如 `10.1016_0304-4076-86-90063-1`）；都没有用标题小写去空格作键。
2. **规范文件名**：`<唯一键>_<第一作者姓>_<年份>.pdf`，如 `2403.07815_Ansari_2024.pdf`。→ 同名不会重复、一眼看出出处。
3. **去重流程**：放入新 PDF 前，先按"唯一键"（或标题）查本表；已存在 → 跳过并提示"重复，已登记于行 N"；不存在 → 按规范重命名后放入对应子文件夹，并在本表登记一行。
4. **状态机**（每篇文献五态）：
   ```
   待下载 → 已下载 → 已阅读 → 已入案例/已用于实验 → 已沉淀
   ```
   - 待下载：清单里列了但还没下载；
   - 已下载：PDF 已放入 `literature/`；
   - 已阅读：AI 已解析内容（案例/要点）；
   - 已入案例/已用于实验：已写入第 23/24 章案例库或研究实验；
   - 已沉淀：可复用模式已写入 KNOWLEDGE 条目。
5. 状态变更由 AI 每次处理后更新本表（改"状态"列即可）。
