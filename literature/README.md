# literature · 文献收集区

这是本书（第 23 章·应用研究 / 第 24 章·方法改进）的**文献收集区**。工作模式：

1. **AI 负责**：全网搜索文献 → 生成清单（三个清单文件）→ 提醒"清单已列完"；
2. **你负责**：按清单把文献（PDF 或条目）放入对应子文件夹；
3. **AI 负责**：基于你放入的文献，不断填充第 23 章（应用案例）与第 24 章（方法改进案例）。

## 收集建议

- 每篇文献按清单条目命名，如 `Bollerslev1986_GARCH.pdf`；
- 清单中标注了「待确认」的条目（个别无 arXiv 预印本的会议论文），收集时以官方页面为准；
- 收集满一批后告诉我"文献已放入"，我将逐篇阅读并填充对应章节的案例（每篇案例含：问题→方法→改进点/应用亮点→结果→与本书概念的对应）。

## 文献管理（去重 + 状态跟踪）

- **索引表**：[文献索引.md](文献索引.md)——唯一键（arXiv ID/DOI）去重、规范命名（`<唯一键>_<作者姓>_<年份>.pdf`）、五态状态机（待下载→已下载→已阅读→已入案例/实验→已沉淀）。
- **放入前查索引**：先按唯一键/标题查 `文献索引.md`，重复则跳过；不重复则规范命名后放入 `应用研究/<领域>/` 或 `方法改进/<热点>/`，并在索引登记。
- **状态更新**：AI 每次处理完文献（阅读/入案例/沉淀）后更新索引的"状态"列。

## 检索词（Google Scholar / Web of Science）

AI 在定题（研究主题确定）时，会生成针对主题的检索式，含 Google Scholar 与 Web of Science 两种格式；也可在 `文献清单-*.md` 中按需补充。
